* искусственного интеллекта;

* развития человека.

# Как можно участвовать

Приветствуются:

* предложения по улучшению;
* обсуждение методологий;
* сообщения об ошибках;
* идеи новых модулей;
* тестирование решений;
* исследовательская работа.

# Правила участия

Просьба соблюдать следующие принципы:

1. Уважительное отношение к участникам.
2. Конструктивная аргументация.
3. Ориентация на практическую пользу.
4. Указание источников при использовании внешних материалов.
5. Соблюдение лицензии проекта.
